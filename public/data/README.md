# Display JSON for the OceanEmbed website

These files are **UI mock / snapshot data**, not the full scientific training corpus.

- `catalog.json` — input/target product list for SIH26066
- `liveOcean.json` — compact live-ocean snapshot
- `nio_surface_latest.json` — North Indian Ocean surface field for the map
- `argo_profiles_latest.json` — Argo-style profiles for validation visuals

The interactive explorer also uses the seeded generator in `src/lib/mockData.js`.
